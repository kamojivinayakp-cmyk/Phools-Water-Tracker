    Set up on iPhone

    Home Screen apps and Safari keep separate data on iOS. Pick one and stick with it so your history stays together.

    1. Add to Home Screen. In Safari tap Share, then Add to Home Screen. It opens full screen like an app, and on iOS 16.4+ it can show alerts while it is open or in the background.
    2. Hourly system reminders. Open Shortcuts, go to Automation, tap +, choose Time of Day, set a time and repeat Daily, pick Run Immediately, add the action Show Notification with the text "Sip time, Phool". Repeat for each time you want, such as 10:00, 12:00, 14:00, 16:00 and 18:00. These work even when the app is closed.
    3. One-tap sip shortcut. In Shortcuts create a shortcut with the action Open URLs and paste the link below. Name it "Sip water", then use Add to Home Screen or say "Hey Siri, sip water". Opening it logs one sip.
